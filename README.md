# Stats-vs-AI-whodunnit
For the analysis examining whether classic statistical approaches or AI better predicts the murderer in Agatha Christie’s novels, the dataset attached here is called AgathaChristie_MissMarple_MainCharacters.txt. The file includes the title of the novel, the characters name, whether the character was the murderer (variable name Killer), the gender of the character (variable name Female), the employment status of the person (variable name Employed), the relationship of the person to the main murder victim (variable name Related), whether the person finically benefits from the main murder (variable name Financial), and AI‑generated assessments from the first chapter of each novel can predict which characters are murderers	(AIch1 and Aipassage).
