# Stats-vs-AI-whodunnit
For the analysis examining whether classic statistical approaches or AI better predicts the murderer in Agatha Christie’s novels, the dataset used for the analysis is available on this GitHub site, entitled "AgathaChristie_MissMarple_MainCharacters_v2.txt". The file includes the title of the novel, the characters name, whether the character was the murderer (variable name Killer), the gender of the character (variable name Female), the employment status of the person (variable name Employed), the relationship of the person to the main murder victim (variable name Related), whether the person finically benefits from the main murder (variable name Financial), and AI‑generated assessments predicting which characters are murderers from the first chapter of each novel from a passage (AIch1passage), first chapter of each novel from the web (AIch1web), and the chapter that determines approximately 20% of the novel (AIch20p).
